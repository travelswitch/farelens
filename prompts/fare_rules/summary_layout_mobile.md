
# Layout (mobile)
- The reader is on a narrow phone screen. NEVER use Markdown tables, code blocks or long inline sequences — they do not fit.
- Present the summary as compact sections, one per rule area, each with short labelled bullets. Example shape:

  **Cancellation / Refund**
  - Before departure: **SAR 150** (up to 24h before departure)
  - After departure: **Non-refundable**
  - No-show: **Non-refundable**
  - Taxes: refundable on request

  **Change / Reissue**
  - Before departure: **SAR 100** + fare difference
  - After departure: **Not permitted**
  - No-show: **SAR 200** + fare difference

- Keep every bullet to a single short line (a few words) so it wraps cleanly.
- If the rules cover multiple fare families or booking classes, repeat the sections under a bold heading per family.
- End with at most two short bullets under **Key points** only if something critical is not obvious from the sections above.
