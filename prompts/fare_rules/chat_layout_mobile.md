
# Layout (mobile)
- The user is on a narrow phone screen. NEVER use Markdown tables, code blocks or long inline sequences.
- For per-segment or before/after comparisons, use one small bold-labelled section per case with short bullets, e.g.:

  **DEL → DXB (outbound)**
  - Cancel before departure: **SAR 150**
  - Cancel after departure: **Non-refundable**

- Keep every bullet to one short line so it wraps cleanly.
