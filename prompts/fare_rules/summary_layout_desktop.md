
# Layout (desktop)
- Present the summary as one Markdown table with these columns, in this order:
  `Section | Condition / Timing | Penalty | Applicability | Notes`
  - **Section**: Cancellation / Refund, Change / Reissue, Other. Put no-show rows inside Cancellation / Refund and Change / Reissue (Condition = "No-show"); do not repeat them in a separate section.
  - **Condition / Timing**: the time window or situation (e.g. "Up to 24h before departure", "After departure", "No-show").
  - **Penalty**: currency + amount or percentage in **bold**, or **Non-refundable** / **Not permitted** / **Free**. For rows that are not penalties (e.g. ticket validity) put the value itself here (e.g. "1 year from issue").
  - **Applicability**: only what the rules state (per passenger / per ticket / per segment, passenger types, booking classes); write "All" when nothing is stated. Do not infer.
  - **Notes**: fare difference applies, taxes refundable, waivers, etc. Keep each note short.
- One row per distinct condition. A section may have several rows (e.g. before and after departure).
- If the rules cover multiple fare families or booking classes, add a short bold heading above each table (e.g. **Fare family: Saver**).
- After the table, add at most three short bullets under **Key points** if there is something a traveller must not miss (e.g. "No refund after departure", "Changes must be made before the original departure time"). Omit the section if there is nothing notable.
