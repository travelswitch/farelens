Airline fare rules, explained.

FareLens is an open-source, self-hosted API and admin UI that turns raw airline fare rules from Amadeus NDC, any GDS or airline API into clear, multilingual summaries, and answers cancellation, change and no-show questions, using the LLM provider you choose.

The problem for GDS / NDC integrators

  • Fare-family, price-class and fare-rule text is passed through exactly as the airline supplies it. The GDS does not generate a short version the way it does for EDIFACT.
  • There is no parameter to control the length, and no standardisation across carriers.
  • The text is often long and inconsistent, with detailed conditions or URLs embedded, which makes it unusable in a B2C booking flow.
  • This is by design. The behaviour is compliant with the NDC standard, so the integrator has to solve it.

FareLens is that solution. Feed it whatever the airline returned and get back a consistent, short, structured summary, plus a Q&A channel for the follow-up questions travellers actually ask. Amadeus, Sabre, Travelport, direct-connect NDC or an airline API all produce the same clean output.

What you get

Summary API

POST raw fare rules, receive Markdown "mini rules": a table on desktop, compact sections on mobile, in the traveller's language.

Chat API

Server-Sent Events Q&A over one or many itinerary segments. Segment-aware and date-aware: "Can I cancel the return on the 12th?"

Bring your own LLM

OpenAI, Azure OpenAI, Anthropic Claude, Google Gemini, Groq or AWS Bedrock. Configure and test from the UI, switch any time.

Caching

Content-digest cache, Redis then Postgres, so identical fare rules never hit the model twice.

Admin UI

Provider setup, API keys, usage analytics (tokens, latency, cache hit rate), prompt editor with live preview, datastore management, playground.

One command

docker compose up brings up the API, Postgres 16 and Redis 7 with zero configuration. MIT licensed.

Who is it for

Online travel agencies (OTAs), airlines, travel management companies, metasearch and booking-engine vendors, and any travel-tech team integrating Amadeus, Sabre, Travelport or NDC content who needs fare rules that customers can actually read.
